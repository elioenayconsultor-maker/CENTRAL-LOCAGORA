# Fase 0 — Resumo executivo

Baseline auditada: Locagora Central V13.2.
Linha alvo: V14.

A V13.2 não foi sobrescrita. A recomendação é reconstrução incremental: primeiro separar público e corporativo por rotas reais; depois implantar autorização por papel, premissas imutavelmente versionadas, CRM e simulador público. Os maiores riscos atuais são estado comercial fragmentado no navegador, configuração comercial com mutação de objetos globais, ausência de suíte formal de testes e autorização insuficiente para a matriz de papéis prevista na V14.
